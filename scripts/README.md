# scripts

Root-level repo tooling. Ticket automation (agent dispatch, label setup, close-time label cleanup) moved to the `askrzypczak/claude-workflow` repo.

- `coverage.ts`: `npm run coverage`. Unit, integration and e2e coverage plus a merged total. Informational only; reports land in `reports/coverage/<kind>`. Also writes `total/coverage-final.json` and `coverage-summary.json` (baseline artifact), the latter only when unit, integration and e2e were all collected. In CI the `e2e` job collects the raw e2e data once (`E2E_COVERAGE=1`, artifact `e2e-raw-coverage`) and the `coverage` job points `COVERAGE_E2E_RAW_DIR` at it so the suite is not re-run; a separate `comment` job holds the only `pull-requests: write` and posts `summary.md` as a sticky comment (hidden marker, edited in place). Optional env: `COVERAGE_BASE_REF` (e.g. `origin/main`; enables patch coverage from `git diff -U0 <ref>...HEAD`) and `COVERAGE_BASELINE` (path to a `coverage-summary.json` from main; enables the delta). Both unset locally means "no baseline" / "no coverable lines changed"; errors never fail the run.
- `coverage-lib.ts`: pure helpers for `coverage.ts` (Istanbul merge, per-kind table, diff parsing, patch coverage, delta and comment formatting). Unit-tested in `coverage-lib.test.ts`.
- `mutate-changed.ts`: `npm run mutate:changed [base-ref]`. Runs Stryker on the production files changed since the merge-base with `base-ref` (default `origin/main`), selected with the `mutate` globs from `stryker.config.json`. Informational: always exits 0. Writes `reports/mutation/comment.md` (posted by the CI `comment` job) and the HTML report to `reports/mutation/`.
- `mutate-lib.ts`: pure helpers for `mutate-changed.ts` (changed-file selection, comment formatting and truncation). Unit-tested in `mutate-lib.test.ts`.
- `vitest-projects.test.ts`: checks that every test file belongs to exactly one vitest project (see `vitest.globs.ts`).
