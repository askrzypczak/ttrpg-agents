# Attribution

`index.json` in this folder lists the folders and WebP file names of the TooManyTokens pack, `IsThisMyRealName/too-many-tokens-dnd` (https://github.com/IsThisMyRealName/too-many-tokens-dnd), at commit `8c791a0e75f1a254aea2ee8f7eaaf0515d693138`. The pack is released under the MIT License, reproduced below.

The index holds only the pack's folder and file names. No images are committed: the MCP server fetches them at run time from the pinned commit. The generator is `scripts/import-too-many-tokens.ts`; the mapping of folders to monster keys is in `folder-keys.json` and the README of this package.
