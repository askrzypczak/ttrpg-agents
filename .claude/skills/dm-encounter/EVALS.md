# dm-encounter evals

Prompt evals for `SKILL.md`. Run each sentence in a fresh `claude -p` session from the repo root with the project MCP server `ttrpg-agents` enabled and `TTRPG_AGENTS_DB` pointing at a throwaway file. "Seeded" means the encounter already holds Goblin Warrior 1-3 and Shadow 1-2, added with `add_monsters` (so each type shares an initiative group). Map states need the bridge running and the Owlbear test scene open: "one map" means one image on the Map layer (Trollskull Manor, aligned to the grid); "two maps" means Trollskull Manor and Sewers; "used" means one map and `use_map` already called; "rooms" means used, with the rooms Taproom (T5:AB11) and Attic (A1:B2) saved. A two-turn row runs its second sentence in the same session with `claude -p --continue`. A sentence passes when the calls match and every number in the answer comes from tool output.
